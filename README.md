# 阪神 複勝判定ボード

競馬の複勝（3着以内）について、「どのレースなら買う価値があるか」を判定して表示するボードです。
当日のオッズを取得し、発走30分前と10分前に判定して更新しています。

**ページ:** https://kumagai108.github.io/keiba-board/

## 何を判定しているか

市場が上位3頭に集中していて、その2番人気をモデルが市場より高く評価していて、
かつ新馬・未勝利・2勝・3勝クラス — この3つが揃ったレースだけ、2番人気の複勝を1点買う戦略です。

該当するのは全レースの8.2%で、ゼロの日も普通にあります。**「買わない」は正常な出力です。**

詳しい仕組みはページ内の「この判定は何をしているのか」を参照してください。

## 注意

- 各レースの「それでも買うなら」の数字は**ほぼすべて期待値マイナス**です。買いの推奨ではありません。
- 掲載している成績は過去データにもとづくもので、将来を保証しません。
- 個人の検証記録であり、投資助言ではありません。馬券の購入は自己責任でお願いします。
